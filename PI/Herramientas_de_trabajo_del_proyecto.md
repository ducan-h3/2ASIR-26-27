**GitLab y OpenProject — Resumen 2º ASIR**
**1. GitLab**
GitLab es una plataforma DevOps basada en Git que permite gestionar el código fuente, controlar versiones y automatizar el desarrollo y despliegue de aplicaciones.
**Funciones principales**
- Repositorios Git: almacenan el código y su historial.
- Control de versiones: permite conocer y recuperar cambios anteriores.
- Branches: permiten desarrollar diferentes funcionalidades de forma independiente.
- Merge Request: permite revisar y fusionar cambios entre ramas.
- Issues: sirven para registrar errores, tareas y mejoras.
- CI/CD: automatiza procesos como pruebas, compilación y despliegue.
- Permisos: permite controlar qué puede hacer cada usuario o grupo.
- Pipelines: ejecutan automáticamente las tareas definidas en CI/CD.
**Conceptos importantes**
Commit: guarda un conjunto de cambios en el repositorio.
Branch: rama independiente del código.
Merge: unión de los cambios de una rama con otra.
Merge Request: solicitud para revisar y fusionar cambios.
Pipeline: conjunto de procesos automáticos de CI/CD.
Runner: máquina que ejecuta los trabajos definidos en un pipeline.
**2. OpenProject**
OpenProject es una plataforma de gestión de proyectos de código abierto. Permite planificar, organizar y controlar proyectos y equipos.
**Funciones principales**
- Creación y organización de proyectos.
- Gestión de tareas e incidencias.
- Asignación de tareas a usuarios.
- Planificación mediante diagramas de Gantt.
- Gestión de tiempos y costes.
- Seguimiento del progreso.
- Gestión de reuniones y documentos.
- Planificación mediante metodologías Agile y Scrum.
**Conceptos importantes**
Tarea: trabajo que debe realizarse.
Hito: punto importante del proyecto.
Gantt: muestra visualmente las tareas, fechas y duración.
Sprint: periodo de trabajo utilizado en metodologías Agile/Scrum.
Work package: elemento de trabajo que puede representar una tarea, incidencia, requisito, etc.
**3. Diferencias**
| GitLab | OpenProject |
|---|---|
| Desarrollo de software | Gestión de proyectos |
| Basado en Git | Gestión de tareas y planificación |
| Repositorios | Proyectos |
| Commits | Work packages |
| Branches | Gantt |
| Merge Requests | Tareas e incidencias |
| CI/CD | Agile/Scrum |
| Pipelines y Runners | Seguimiento de tiempo y costes 


**4. Ejemplo práctico**
Una empresa desarrolla una aplicación:
**OpenProject se puede utilizar para:**
- Crear el proyecto.
- Dividirlo en tareas.
- Asignar tareas a los trabajadores.
- Establecer fechas.
- Controlar el progreso.
**GitLab se puede utilizar para:**
- Guardar el código.
- Crear ramas para nuevas funciones.
- Registrar commits.
- Revisar Merge Requests.
- Ejecutar pruebas automáticamente.
- Desplegar la aplicación mediante CI/CD.
**Para memorizar**
OpenProject = planificar y gestionar el proyecto.
GitLab = desarrollar, versionar y automatizar el software.
