**MODOS DE CONEXION DE MAQUINA VIRTUAL Y SUS DEFINICIONES**
-NAT: Da internet a la maquina virtual directamente mediante el PC
-Adaptador Puente: Conecta la maquina virtual directamente a la red del router 
-Red interna: Conecta solo las maquinas virtuales entre ellas 
-Adaptador solo anfitrión: conecta el PC con las maquinas virtuales sin internet
-Controlador genérico: permite usar conexiones de red personalizadas
-Red NAT: permite que varias maquinas virtuales se comuniquen y tengan internet
-Red en la nube: conecta la maquina virtual a una red de Oracle Cloud
